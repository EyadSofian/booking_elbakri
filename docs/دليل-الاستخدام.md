# دليل الاستخدام — البكري أوفرسيز

الداشبورد دي مكان واحد بدل الشيتات: **المبيعات بتسجل الحجز، والعمليات بتنفذه**، والكل شايف نفس الحالة.
كل شاشة فيها تسجيل وتعديل وتغيير حالة — مفيش حاجة للعرض بس.

---

## القائمة (٨ أماكن بس)

| المكان | بيستخدمه | فيه إيه |
| --- | --- | --- |
| **الرئيسية** | الكل | ملخص النهارده وبكره: الوصول والمغادرة من الفنادق، جدول الانتقالات، الطلبات المستنية، مبيعات الشهر |
| **المبيعات** | المبيعات | حجوزات العملاء بأسعارها — زي شيت المبيعات بالظبط |
| **الفنادق** | العمليات | حجوزات الفنادق + الدفع للفندق |
| **الانتقالات** | العمليات | انتقالات المطار والفنادق + السواق |
| **الرحلات** | العمليات | الرحلات والأنشطة |
| **التأشيرات** | العمليات | طلبات الفيزا |
| **التقارير** | الإدارة والمبيعات | فلوس الشهر وعمولة كل بائع، وحجم الشغل لكل وكالة |
| **الإعدادات** | الإدارة | الفريق، الوكالات، الفنادق، الاستيراد من إكسل |

الرقم البرتقالي جنب أي مكان في القائمة = عدد الطلبات اللي لسه محتاجة حد يتحرك فيها.

---

## الحالات (واحدة في كل مكان)

| الحالة | معناها |
| --- | --- |
| 🟠 **طلب جديد** | لسه متسجل — محدش اتحرك فيه |
| 🔵 **قيد التنفيذ** | شغالين عليه |
| 🟢 **مؤكد** | متأكد مع المورد (الفندق / السواق / ...) |
| ⚪ **تم** | خلص |
| 🔴 **ملغي** | مش هيتم |

تغيير الحالة: **اضغط على الحالة نفسها** في أي قائمة أو صفحة واختار الجديدة. كل تغيير بيتسجل باسم اللي عمله وميعاده.

---

## المبيعات: تسجيل حجز

1. **المبيعات ← حجز مبيعات جديد** (أو زرار **تسجيل** البرتقالي فوق).
2. اكتب بيانات العميل، الأفراد والغرف، وتاريخ الرحلة.
3. في **الأسعار** اكتب التكلفة والبيع لكل خدمة بعتها (الفندق، الطيران وعمولته، الانتقالات، خدمات أخرى).
   الربح والإجماليات وعمولة البائع (١٠٪) بتتحسب لوحدها في الكارت اللي على الجنب.
4. لو العميل دفع حاجة اكتبها في **مدفوع دلوقتي**.
5. علّم **احجز الفندق** و/أو **رتّب الانتقالات** عشان يوصل طلب للعمليات.
6. **حفظ الحجز**.

في صفحة الحجز تقدر: تسجل دفعات جديدة، تشوف حالة كل طلب في العمليات، وتطلب فندق / انتقال / رحلة / فيزا زيادة.

## العمليات: تنفيذ الطلبات

* الطلبات الجاية من المبيعات بتظهر في التاب بتاعها كـ **طلب جديد** ومكتوب عليها «طلب من حجز المبيعات S-…».
* افتح الطلب (اضغط على السطر) ← **تعديل** ← كمّل البيانات (رقم التأكيد، السواق، الميعاد...) ← **حفظ**.
* غيّر الحالة لـ **مؤكد** لما تتأكد.
* في الانتقالات: زرار **إضافة العودة** بيعمل رحلة الرجوع بنفس البيانات ومقلوبة من/إلى.
* **نسخة**: يعمل حجز جديد بنفس البيانات (مثلاً غرفة تانية لنفس النزيل).
* تسجيل حجز جديد مباشرة (من وكالة زي سما أو تذكرة): زرار **حجز جديد** في أي تاب.

## البحث

المربع اللي فوق بيدور في كل الحجوزات مرة واحدة: اسم، موبايل، فندق، رقم رحلة طيران، أو رقم الحجز (مثلاً H-120).

## إكسل

* **تنزيل**: زرار **إكسل** في أي قائمة بينزّل اللي ظاهر قدامك (بنفس الفلاتر) بنفس أعمدة الشيت.
* **رفع الشيتات**: الإعدادات ← استيراد من إكسل ← اختار الملف ← **افحص** ← **استيراد**.
  الصفوف اللي اتستوردت قبل كده بتتجاهل، فتقدر ترفع الشيت بعد تحديثه تاني.
  ارفع **شيت الفنادق قبل شيت الدفعات**.

## الفريق والصلاحيات

| الدور | يقدر |
| --- | --- |
| **مدير** | كل حاجة، ومعاها المستخدمين والإعدادات |
| **مبيعات** | يسجل المبيعات والدفعات، ويبعت طلبات للعمليات، ويشوف كل التابات |
| **عمليات** | يدير الفنادق والانتقالات والرحلات والتأشيرات، والوكالات والفنادق، والاستيراد |

إضافة شخص: الإعدادات ← الفريق ← إضافة شخص.

## الوكالات والفنادق

الشيتات القديمة فيها نفس الاسم مكتوب كذا طريقة («Safir Sharm» و«Safir Sharm Waterfalls Resort»).
من الإعدادات ← الفنادق (أو الوكالات) ← **…** ← **دمج في…** اختار الاسم الصح، وكل الحجوزات هتتنقل عليه.
